# turastory-workflow

에이전트와 함께 아이디어를 설계로 키워 가는 문서 워크플로입니다.
사용자가 말한 원문, 논의 중인 설계, 확정된 설계를 서로 다른 파일에 나눠 기록합니다.
에이전트가 이 규칙을 읽고 따르도록 `AGENTS.md`에 적어 둡니다.

## 원칙

1. 사용자가 입력한 아이디어는 원문 그대로 이력으로 남깁니다. 요약하거나 다듬지 않습니다.
2. 진행 중인 논의, 미정 항목, 에이전트의 제안은 `draft.md`에 기록합니다.
3. 확정된 디자인 철학과 구조는 `design.md`에 기록하고, `draft.md`에서는 해결된 논의를 뺍니다.
4. 한 항목에 결정된 부분과 미정인 부분이 섞이면 나눠서 각자의 파일에 둡니다.
5. 에이전트의 제안은 사용자가 채택해도 원문 기록에 넣지 않습니다. 원문 기록에는 사용자가 직접 말한 내용만 둡니다.
6. 같은 설계의 사본이나 변경 이력을 여러 파일에 쌓지 않습니다. 이력은 git에 남깁니다.

## 파일

| 파일 | 담는 것 | 바뀌는 방식 |
|---|---|---|
| `AGENTS.md` | 에이전트가 따를 문서 작업 규칙 | 규칙을 바꿀 때만 |
| `CLAUDE.md` | Claude Code가 `AGENTS.md`를 읽게 하는 import 한 줄 | 거의 안 바뀜 |
| `thoughts.md` | 사용자 아이디어 원문과 발언 시각 | 끝에 추가만 |
| `draft.md` | 논의 중인 설계, 미정 항목, 에이전트 제안, 확인할 것, 진행 계획 초안 | 결정되면 해당 내용을 뺌 |
| `design.md` | 채택된 목표, 디자인 철학, 구조 | 채택될 때 반영 |

## 흐름

```text
사용자 발언
  -> thoughts.md 끝에 원문 기록
  -> draft.md에 논의할 설계안과 미정 항목으로 정리
  -> 사용자가 채택
  -> design.md(또는 주제별 결정 문서)에 반영하고 draft.md에서 정리
```

## 사용법

1. `template/`의 파일을 프로젝트의 문서 디렉터리에 복사합니다.
2. `AGENTS.md`와 각 파일 머리말의 `<주제>`를 프로젝트 주제로 바꿉니다.
3. 결정 문서가 하나로 부족하면 `design.md` 옆에 주제별 결정 문서를 추가합니다. 예를 들어 게임이라면 규칙 문서와 플레이 시나리오 문서를 둘 수 있습니다. 추가한 파일은 `AGENTS.md`의 "문서의 구분"에 등록합니다.
4. 에이전트에게 아이디어를 말하면 `AGENTS.md` 규칙에 따라 원문이 기록되고, 논의와 결정이 나뉘어 정리됩니다.
